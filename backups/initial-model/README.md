# Initial model backup

Snapshot of the ICU model at repository commit `e4f8254` (2026-11-05), before further edits.

- `icu.blend`: editable Blender scene
- `icu.glb`: exported model
- `icu.glb.gz`: compressed model used by the site
- `icu_spec.json`: model dimensions, materials, equipment, lighting, and camera settings

To restore the model files, copy these files back to `downloads/icu.blend`, `downloads/icu.glb`, `assets/model/icu.glb.gz`, and `spec/icu_spec.json` respectively.
